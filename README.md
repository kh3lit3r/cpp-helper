# C++ Помощник — расширение для VS Code

Небольшое учебное расширение для Visual Studio Code, написанное на TypeScript.
Оно упрощает три рутинные операции при работе с C++: добавление защиты заголовка,
создание заготовки класса и быстрое переключение между заголовочным файлом и файлом реализации.

## Возможности

| Команда | Что делает |
|---|---|
| `C++ Помощник: Вставить #pragma once` | Добавляет `#pragma once` в начало текущего файла. Если директива уже есть, показывает уведомление и ничего не меняет. |
| `C++ Помощник: Вставить заготовку класса` | Запрашивает имя класса и вставляет в позицию курсора каркас: конструктор, деструктор, запрещённое копирование и секцию `private`. |
| `C++ Помощник: Переключиться между .h и .cpp` | Открывает парный файл. Для `foo.h` ищет `foo.cpp`, и наоборот. |

Переключение между файлами также доступно:

- по горячей клавише **Alt+O** (в C/C++ файлах);
- через контекстное меню редактора.

Парный файл ищется в той же папке, а также в соседних папках `src/` и `include/`.
Поддерживаемые расширения: заголовки `.h`, `.hpp`, `.hh`, `.hxx`; исходники `.cpp`, `.cc`, `.cxx`, `.c`.

### Пример заготовки класса

Для имени `Widget` будет вставлено:

```cpp
class Widget {
public:
    Widget();
    ~Widget();

    Widget(const Widget&) = delete;
    Widget& operator=(const Widget&) = delete;

private:
    // здесь окажется курсор
};
```

## Требования

- Visual Studio Code версии 1.80 или новее;
- Node.js (рекомендуется версия 18 или новее) и npm — для сборки из исходников.

## Структура проекта

```

├── .vscode/
│   ├── launch.json      # конфигурация запуска расширения для отладки
│   └── tasks.json       # задача сборки (npm: compile)
├── src/
│   └── extension.ts     # весь код расширения

├── .vscodeignore        # что не включать в пакет .vsix
├── .gitignore
├── README.md            # этот файл
└── REPORT.md            # отчёт о проделанной работе
```

## Сборка и запуск

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Скомпилируйте TypeScript в JavaScript:

   ```bash
   npm run compile
   ```

   Результат появится в папке `out/`.

3. Откройте папку проекта в VS Code и нажмите **F5**.
   Откроется новое окно «Extension Development Host» с загруженным расширением.

4. В этом окне откройте любой `.cpp` или `.h` файл, нажмите **Ctrl+Shift+P**
   (на macOS — **Cmd+Shift+P**) и начните вводить `C++ Помощник`.

Для автоматической пересборки при изменении кода используйте:

```bash
npm run watch
```

## Установка как пакета (.vsix)

```bash
npm install -g @vscode/vsce
vsce package
```

Команда создаст файл `cpp-helper-0.0.1.vsix`. Установить его можно так:

- в VS Code: панель «Расширения» → меню «…» → «Установить из VSIX…»;
- или из терминала: `code --install-extension cpp-helper-0.0.1.vsix`.

Перед упаковкой замените в `package.json` значение поля `publisher` на своё.

## Как это работает

- Расширение активируется автоматически при открытии файла на языке C или C++
  (`activationEvents` в `package.json`).
- В функции `activate` из `src/extension.ts` регистрируются три команды через
  `vscode.commands.registerCommand`.
- Заготовка класса вставляется как `SnippetString`, поэтому курсор сразу
  встаёт в нужное место.
- Имя класса проверяется регулярным выражением: допускаются только корректные
  идентификаторы C++.

## Идеи для развития

- создание пары файлов `.h` и `.cpp` одной командой;
- генерация определений методов в `.cpp` по объявлениям из `.h`;
- настройки расширения (стиль защиты заголовка, шаблон класса);
- автоматические тесты на `@vscode/test-electron`.
